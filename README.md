# beatandmoney-videos

Estrutura de produção de vídeo do canal **Beat & Money**. Veja `CHECKLIST.md` para o passo a passo
e `brand/brand-guide.md` para a identidade visual.

Esse repositório guarda **scripts e identidade**, não os vídeos em si (eles são grandes demais e
ficam fora do git — veja `.gitignore`). Cada vídeo novo final é entregue pelo Claude Code
diretamente pra você no momento da produção.
